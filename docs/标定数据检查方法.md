# 三相机标定数据检查

这一步检查录制数据是否值得送入标定求解器，不生成相机内参、外参或深度。图像检测成功也不代表标定精度合格。

## 1. 检查文件与全部图像时间戳

输入必须是已经正常结束、包含 `metadata.yaml` 的 ROS 2 MCAP 目录。

```bash
cd /home/onana/ros2_ws
source /opt/ros/jazzy/setup.bash
python3 tools/uvc_calibration/check_recording_quality.py \
  /home/onana/calibration_data/SESSION/bag \
  --output /home/onana/calibration_data/SESSION/quality_2s \
  --period 2 --workers 2
```

工具核对每个 MCAP 的起止 magic、记录长度、Footer 和所有话题消息计数，并要求计数与 metadata 一致。扫描全部三路图像的原始 `header.stamp`，统计重复/倒退、平均帧率、最长间断和双目完全同戳数量。它按 MCAP 的未分块 fastwrite 格式跳过大部分像素载荷，遇到 Chunk 会明确报错，不静默漏读。**这个快速审计没有校验全部像素字节的 CRC。**

掉帧不自动等于整包无效；匹配必须依据保留下来的原始时间戳，不能按帧序号硬配。录制器的缓存丢失统计还包括 CameraInfo/status，不能将总丢失数直接当作图像丢帧数。

## 2. 使用真正的 Kalibr 检测器

本次打印板为 tag36h11，6×6，完整黑框边长 32.5 mm、间隔 9.75 mm。黑边宽是 2 个编码格；默认 1 格的 OpenCV 检测器会漏检。本机实际 Kalibr 的 `CameraCalibrator.py` 设置 `minTagsForValidObs = max(tagRows, tagCols) + 1`，因此本板默认至少需要 7 个检测标签。

第一步的 OpenCV 结果仅用于初筛：即使设置黑边为 2 格，它在本次实拍图上仍明显少于 Kalibr，不可单凭它要求重拍。

利用扫描生成的索引，导出更密的稀疏样本：

```bash
python3 tools/uvc_calibration/export_quality_samples.py \
  /home/onana/calibration_data/SESSION/quality_2s \
  --output /home/onana/calibration_data/SESSION/official_inputs_1s --period 1
```

导出为原分辨率灰度 PNG，保留源 BGR 图像索引和时间戳；不缩放、不裁切、不经过 JPEG。PNG 解码后的像素哈希会在检测前核对。将样本复制到有现成 Kalibr 环境的电脑后执行：

```bash
python3 tools/uvc_calibration/kalibr_sample_audit.py \
  /path/to/official_inputs_1s --output /path/to/official_audit_1s
```

此命令需要加载实际 Kalibr 的 `aslam_cv` / `aslam_cameras_april` 环境。脚本设置黑边 2、最少 7 标签、关闭几何角点异常过滤，与当前 Kalibr 相机标定的检测配置一致。API 所需的虚拟相机参数仅用于调用角点提取接口，**不作为物理相机标定结果输出**。

## 3. 检查共同角点与覆盖

- 分别统计左目、右目、RGB 有多少抽样图能被 Kalibr 接受，检查画面中心、边缘和不同倾角的覆盖。
- 在主机图像时间戳差不超过 25 ms 的抽样对中，统计两路均被接受且有相同角点 ID 的次数。
- 左目—右目，以及 RGB—至少一路黑白相机，需要形成连通的共同观测关系。整块板不必同时完整入镜；只拍三组互不相交的单相机画面不足以初始化当前 Kalibr 的相机共视图。
- 抽样帧数不等于独立标定姿态数；板连续不动时的多张图不增加同等几何约束。25 ms 只约束主机接收时间，不证明曝光同步，因此采集应停稳后取帧。

## 4. 求解之后还要验收

检查求解是否收敛、内参与基线是否合理、各相机重投影残差与图像边缘残差，以及独立验证集上的表现。再检查双目校正后的纵向对齐及实测距离误差。只有这一阶段通过，才能把结果导入运行链路；不能把“检测到标签”当成完成标定。

## 下一次录制的时长与吞吐

`ros2 bag record --max-bag-duration` 是分包时长，**不是录制总时长限制**。需要总时长限制时，应由外部墙钟计时器向 recorder 发送 SIGINT，等待缓存和 metadata 正常落盘，并确认进程退出；不能只依赖此参数。

几何标定不需要将 30 fps 的所有原始帧永久写盘。可按现有采集方案把相机发布频率降至约 4 Hz，保持采集分辨率、镜头模式、焦点与方向不变，并在板停稳后采样；这不适用于动态相机—IMU 标定。当前 30 fps 未压缩三路约 350 MB/s，已经实测在后段出现写盘丢帧。
