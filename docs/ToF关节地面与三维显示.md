# ToF 关节地面过滤与机身三维显示

2026-11-13：Kalo 18081 接入统一 C++ 运动学几何。网页显示现用电控模型的8个实测关节、轮子/轮辐、IMU原点，以及CAD的4路ToF、上右RGB、下方左右灰度相机；未安装的上左相机不显示。拖动模型旋转，滚轮缩放；姿态缺失/关节过期时不伪造零骨架。

`wla_tof/tof_obstacles` 根据实测 `/joint_states`、原 `/imu/data` 和电控URDF导出的关节/轮圆柱几何计算支撑平面，不读取目标站高。用户确认当前双轮接触同一平地，配置为 `support_mode=both`；两侧轮底推算高度差超过5cm或输入失效则不发布过滤结果。该接触模式是人工确认的测试工况，不代表电控接触观测器已验证。

ToF 的基础测距范围改为0.15～4m，随后保留支撑平面以上5～50cm的障碍点；原始基础预览与过滤结果分别提供图层。`/robot_state/geometry` 与过滤器使用同一个C++ FK结果，浏览器不另写一套腿部模型。不修改电控模型、零位或运动控制。

参数、话题、启动、日志和测试命令见 [wla_tof README](../src/wla_tof/README.md)。本页取代标准状态接口文档中“仅机身方盒示意、没有任何高度显示”的旧网页描述；`wla_robot_state` 适配器本身仍只转发实测关节和姿态，不估计全局位置。

验证记录：Orin编译通过，C++2项测试通过；域211接收器PTY测试、域212关节地面/高度过滤/过期与恢复测试通过；网页状态与CDR回归通过。真机已观察四路持续接收、CRC/I²C/序号计数正常、过滤点云输出和全部几何图元。用已知尺寸物体核验测距与地面剔除仍是物理精度验收项。

传感器CAD根原点对接和光学投影方向尚待实物核对，保留 `geometry_calibrated=false`；此结果不是SLAM定位或已验证的运动避障输入。机器人悬空/单轮接地/坡面时重新配置工况，不能沿用双轮平地假设。
