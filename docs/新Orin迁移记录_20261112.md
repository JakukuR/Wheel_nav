## 系统和依赖

两端 Ubuntu 24.04 aarch64、ROS 2 Jazzy、Python 3.12、CUDA 13.2。源 Jetson R39.2.1，目标 R39.2.0。目标安装需要的 Nav2、RTAB-Map、ROS 相机/滤波、GTSAM、BehaviorTree、编译和 Python 依赖。APT 版本存在差异：Nav2 1.3.12→1.3.13，RTAB-Map 0.22.1→0.23.13，RealSense 4.58.1→4.58.4，BehaviorTree.CPP 4.9.0→4.10.0；均以目标实际编译/检查为准。

目标直接联网/DNS不可用，安装时使用临时 SSH SOCKS 转发，未改系统 DNS、软件源或关闭证书校验。转发只在维护 SSH 会话存在时有效，不能当作长期联网配置。代码与大依赖直接由源机流式传到目标，不在维护电脑暂存完整环境。

系统曾停在 1970 年，经用户授权校正 UTC 并写入 RTC，启用自动 NTP；当前外网受限，`NTPSynchronized=no`，不能宣称已锁定网络时钟。应在正常联网后检查 `timedatectl`。

OpenVINS 首次编译缺 ArUco 头文件：系统 NVIDIA OpenCV 4.8 开发文件没有 contrib，而 ROS Python/cv_bridge 使用 Ubuntu OpenCV 4.6。处理为在 `.runtime/opencv46/root` 解包 Ubuntu 4.6 开发包，与已有 4.6 运行库配合；未替换或降级 NVIDIA 系统 OpenCV。OpenVINS 三个包的 CMake 按其原注释意图改为优先找 OpenCV 4，再回退 3，避免第一次找 3 覆盖显式指定的 4.6 路径。

重建命令：

```bash
source /opt/ros/jazzy/setup.bash
source /home/onana/r680_chassis_candidate_ws/install/setup.bash
cd /home/onana/ros2_ws
export CMAKE_BUILD_PARALLEL_LEVEL=1 MAKEFLAGS=-j1
export CMAKE_PREFIX_PATH=/home/onana/.local/wla_mpc_deps:$CMAKE_PREFIX_PATH
export LD_LIBRARY_PATH=/home/onana/.local/wla_mpc_deps/lib:$LD_LIBRARY_PATH
colcon build --executor sequential --symlink-install \
  --cmake-args -DCMAKE_BUILD_TYPE=Release \
  -DOpenCV_DIR=/home/onana/ros2_ws/.runtime/opencv46/root/usr/lib/aarch64-linux-gnu/cmake/opencv4 \
  -DCUVSLAM_SOURCE_DIR=/home/onana/ros2_ws/.runtime/cuvslam_validation/cuVSLAM \
  -DCUVSLAM_BUILD_DIR=/home/onana/ros2_ws/.runtime/cuvslam_validation/sdk_build
```

该命令为完整重建入口；构建结果以文末验证记录为准。若迁移本前缀到其他用户名/目录，私有 OpenCV 软链接、venv 和 SDK RPATH 需要重新检查。
