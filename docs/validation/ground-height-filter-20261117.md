# 地面高度滤除点云测试（2026-11-17）

按用户要求撤下 2d475fe 新增的局部栅格方案，保留此前已验证的支撑约束平面拟合，后续只做按高度筛点。本版不生成占据栅格，不发布拟合地面 TF，也不连接运动控制。旧原始距离场面板从主页面撤下，其独立源码未删除、此次重启后未启动。

## 实际链路

LAS2-S FP16 深度 384×216（384×288 网络填充输入，目标 20 Hz）→ 5 Hz 最新深度采样（像素步长 3，深度 0.15～3 m）→ 按该帧支撑参考约束拟合 → 滤除 `abs(n·p+h) <= 0.015 m` 的点 → PointCloud2。

5°/4 cm 支撑一致性、拟合覆盖与输入新鲜度检查保持原值。输出包含凸起、低矮模糊带和低于平面的点；没有按机器人高度再截断。红/黄/紫只用于显示分类，3 cm 分类线不改变 1.5 cm 滤除阈值。去掉了原栅格的 XY 范围裁剪，不再因落在栅格外而丢弃深度范围内的点。

- 输出 `/camera/stereo/points_ground_filtered`，frame `sunplus_left_rect_optical_frame`，有效帧使用输入深度原始时间戳（不经 double 回转）。
- CAD/光学轴假设仅用于平面筛选；筛选后的点逆变换回原校正相机坐标。未发布机身—相机新 TF。
- 点云按订阅需求输出；诊断 `/r680/debug/stereo/ground_filter`。关闭消费者后不做拟合，输入接收仍保留。
- 输入失效时发布空点云和 `available:false`；空点云不表示已观测自由空间，当前无导航消费者。
- `/ground-filter-lite.html` 及主页面显示滤后点云，可勾选绿色地面叠加。显示用平面坐标展开是前端可视化约定，不作为 ROS frame。
- 原 `ground_map` 节点、栅格接口、Nav2 测试配置/脚本、旧地图页面与专用 TF 广播已移除。几何源时间戳改动保留，供同帧筛选使用。

## 后续调查方向（未部署）

优先研究机器人中心高程图与局部地形可通行性，区分地面/坡道/台阶、机器人动作能力、障碍层与未知区；不把整个地面统一删除视为完整导航方案。

- https://github.com/leggedrobotics/elevation_mapping ：点云、位姿及不确定性结合的机器人中心高程图，可接深度/双目或激光传感器。
- https://github.com/leggedrobotics/elevation_mapping_cupy ：GPU 高程融合、可通行性与平面分割相关公开实现。
- https://github.com/Polyacetone/HWSentryNav26 ：已知赛场预建地图、人工地形方向标注和在线地图差分；前一轮已核查源码，不能直接等同于未知环境的自动地面识别。

本版仍为平地单帧点云测试；绝对光学—机身外参、接触状态和运动位姿的不确定性尚未解决。后续方案研究不自动授权切换运行链路。
