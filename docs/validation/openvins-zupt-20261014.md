# OpenVINS D455 ZUPT 接入与静止实测（2026-10-14）

## 改动

- 启用 OpenVINS 自带 ZUPT，不改写其残差、EKF 或静止检测算法。
- D455 配置：try_zupt=true；zupt_chi2_multipler=1；zupt_noise_multiplier=10；zupt_max_velocity=0.1；zupt_max_disparity=0；zupt_only_at_beginning=false。
- 取消前端对 ZUPT 的禁止；单独报告接受的 ZUPT 次数、时间和 STATIONARY 状态，不伪造 MSCKF 更新或视觉时间。
- 修正初始化可用性判定：内部初始化成功且已接受 ZUPT 时，也允许输出；避免静止时普通图像处理计时尚未建立造成“内部已 ZUPT、外部仍未初始化”。
- 新增 imu_diagnostics，读取实际内部 bg/ba 与对应时间，报告当前测量及纠正后角速度、世界系去重力加速度。不是从 odom 反推偏置。
- 新鲜且不确定度合格的静止里程计允许进入现有导航接口。地图定位仍需 RTAB-Map 的真实匹配/位姿证据，运动授权和接地判断不变。
- 未恢复 propagate_without_camera；未改 IMU 噪声、外参、RealSense 驱动或底盘参数。

## 边界

这是同一时段“原始测量 vs 内部偏置纠正结果”的比较，不是严格同包 ZUPT 开关 A/B，也不是与旧发散片段的同条件对照。静止时偏置/姿态可共同吸收测量误差，不能把单姿态得到的 ba 当作完整硬件内参标定。验证没有覆盖运动中的错误触发、转向精度、遮挡搬运或全导航实车验收。

RealSense 2 模式仍有此前确认的 COPY 行为；这次未修驱动，不能将本结果用于证明插值缺陷已解决。
