# Agent 附近探索动作映射

本实现只映射 Agent 已选中的 `explore / builtin-1 / 前往区域` 阶段，不调用 ROS `explore` 或 `explore_lite`，不改候选评分、人格或动作选择逻辑。一次动作导航到一个附近点，随后停车观察；不会以不断移动的圆心连续随机游走。

## 执行链

`Agent 已选动作 → configured_hybrid_adapter → NearbyExploreAdapter → RosBehaviorTransport → BehaviorTask 行为树 → navigation_task_gateway → ComputePathToPose → NavigateToPose`。

阶段映射为：区域选择（静止）→ 前往区域（附近安全目标导航）→ 区域巡视（停车观察）。这里的巡视不再要求额外的朝向原语路线。混合执行模式原有的动画呈现、实际停车证据和执行许可仍有效。

附近搜索使用新鲜的 `/global_costmap/costmap` 和 `map → r680_mapping_floor` TF。搜索中心在本次导航阶段开始时固定。默认目标距离 1–3 米，整条预规划路径不离开中心半径 3 米，长度不超过 6 米。运行中越出范围、定位健康失效、目标被占据或必要地图/TF 超时会撤销任务；这不意味着物理制动一定能恰在边界完成。

## 先搜索安全区域，再随机选点

1. 截取车辆周围地图，构造障碍累计表；未知、障碍和非零膨胀代价均不可通行。
2. 按已有策略的 `robot_radius_m + 0.25m` 净空，保守地检查栅格邻域。地图外部同样不可通行。
3. 从车辆所在格进行有距离上限的连通搜索，禁止斜穿障碍角。先找出所有附近安全可达区域，再随机排列、空间分散地选出候选点；不是任意撒点碰运气。
4. 按顺序请求 Nav2 规划。某点被拒绝、路径为空、太窄或绕远时，继续尝试下一个安全候选；默认最多 16 次规划，解析总等待约 9 秒，每次最多 2 秒。上游 BT 原有 12 秒解析期限保留。
5. 对规划返回的整条路径按不大于半个栅格的间隔检查净空，避免稀疏路径顶点跨过墙、未知区或窄口。下发前再次检查当前地图和车位。

附近确实没有满足净空的连通区域时返回 `NO_SAFE_CONNECTED_NEARBY_REGION`；有候选但规划服务/路径检查在预算内均未成功时返回 `NEARBY_PLANNER_EXHAUSTED_OR_UNAVAILABLE`。不会以不安全目标换取任务“成功”，也不会因首个坏候选直接终止。

## 配置与身份绑定

Agent 与网关读取同一个地图和策略文件。策略已有 `goal_safety.robot_radius_m`（或 `dynamic_approach.robot_radius_m`）时默认安装附近探索映射。没有底盘尺寸时不自动猜测，不安装此映射。可以覆盖：

```json
{
  "nearby_exploration": {
    "enabled": true,
    "owner": "agent",
    "robot_radius_m": 0.29,
    "min_distance_m": 1.0,
    "max_distance_m": 3.0,
    "clearance_margin_m": 0.25,
    "max_path_m": 6.0,
    "samples": 64,
    "max_plans": 16
  }
}
```

上述 0.29m 仅展示字段，实际沿用对应机器已有尺寸配置；默认映射不会修改该尺寸。`samples` 是完成连通搜索后保留的候选上限。设置 `enabled:false` 可关闭附近映射，继续使用显式静态导航路线。已有静态 `explore/前往区域` 路线在附近映射开启时被替代，其他动作路线不变。默认 owner 为 `agent`，不同 owner 必须在双方一致配置。

目标用每个动作会话独立的 `nearby-explore:<id>` 配方标识，指纹绑定地图版本和搜索参数；不是地图家具点，没有伪造位置写入语义图。实际坐标只由网关从当前地图计算。保留原有双路租约、独占导航、定向取消、真实终态后持续停车确认；一次阶段只派发一个移动目标。导航阶段上限 60 秒。Agent 的底盘准入支持 `automatic_authorized`，不再把手柄 `armed=false` 误当成自主未授权；仍检查 AUTO、NAV 源和软件急停。
