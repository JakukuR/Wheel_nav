## 实测

- 第 154 帧停止前有 489 个视觉观测，已注册 1500 个 IMU 样本。
- 拒绝矩阵对角线约为 `[-0.0737548, 0.00217229, -0.000606109, 0.00000196166, -0.00000515, -0.0000000598607]`。
- X 方差为 −0.07375 m²，不能解释为接近零的浮点误差，不适合直接取绝对值/强行清零。

- 第一故障出现时日志没有 `Lost IMU msgs`；这说明当前该故障不能归因于 IMU 平均频率不足。

本次仅确认 SDK 估计输出不合法，没有证明其根因是某一个外参或噪声参数。当前车身 IMU/相机时延、精确外参、IMU 噪声参数仍使用临时标定；静止下强制关键帧初始化也需要进一步验证可观性。下一步应使用同一组左右目、原始 IMU 记录，比较初始化运动段和静止段，核验时延/外参及 SDK 信息矩阵，不能将运动健康锁放宽当成修复。
