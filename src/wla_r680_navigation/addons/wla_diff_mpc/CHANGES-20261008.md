# 障碍距离制动与有界碰撞重试

日期：2026-10-08；基线：`6bacf93`。

原 MPC 对参考路径求解后才检查预测足迹，参考路径包含动态障碍时可能持续求解同一条不可执行的轨迹。现在先测量参考轨迹的碰撞距离，用以下条件限制速度：

```text
v × obstacle_reaction_time + v² / (2 × obstacle_braking_deceleration)
    <= collision_distance - obstacle_stop_margin
```

默认减速度 0.4 m/s²、响应时间 0.7 s、额外停止余量 0.10 m，均可在 Nav2 的 FollowPath 参数中调整。它们是保守控制参数，不是新的底盘响应测量结果。

碰撞检查包含足迹边界和内部栅格，在预测点之间按半个地图格、最大 0.05 rad 插值；预测采用优化后的输入从当前位置进行非线性差速积分。第一次预测不安全时，在剩余周期预算内以 `collision_retry_speed_scale: 0.5` 降低速度再解一次。保持 25 ms 单次求解限时和 45 ms 周期限时；仍不安全或超时则返回 NoValidControl，由 Nav2 零速及重规划处理。

该控制器仍跟踪全局路径，不实现完整障碍约束的绕行优化。全局规划器需要获得动态障碍信息，才能提供新的可执行路线。

`obstacle_braking_regression` 验证制动公式、停止余量、预测点间薄障碍、角度环绕、非线性积分及降低速度后安全的 QP 结果。现有 `qp_regression`、`reference_regression` 同时通过。尚未做实车运动测试。
