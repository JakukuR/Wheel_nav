# OpenVINS 一次性运动初始化

用户明确要求实验中由底盘自动以约 0.2 m/s 和 0.5 rad/s 前进转向，不依赖尚未存在的 VIO/地图许可或接地检测。入口为：

```bash
cd ~/ros2_ws
./r680_nav.sh --openvins --openvins-imu d455 \
  --map map-2026-10-08-1 --test-scan-only --openvins-motion-init
```

这是显式开启的实车运动实验。操作者应先确认平地、前方及转向侧空旷，不要求手柄在线。没有接地、深度或障碍物检测；不得用于无人值守、抱起、桌面、台阶附近启动。保留独立手柄接管/急停、传感器时效、轮速里程范围及硬时限。未给此参数的启动行为不变。

程序最多等待 90 秒获取有效双目/IMU 前端报告、新鲜轮速、MANUAL/NAV 仲裁状态；有手柄时要求无人工非零输入；保持静止 5 秒。验证正常导航 command_guard 硬件输出关闭后，先发布零速握手，仅为本次初始化请求 AUTO/NAV。以 0.2 秒斜坡达到 0.2 m/s、0.5 rad/s，总命令时间最多 1 秒（理想积分约 0.18 m、0.45 rad，不是实测刹停距离）。轮速累计路程 0.30 m、转角 0.65 rad 或实测速度超过 0.30 m/s、0.75 rad/s 即中止。

正常结束、手柄输入、急停、前端代次变化、传感器报告中断、SIGINT/SIGTERM 或异常均归零并撤销本次 AUTO 请求。仲裁已有命令超时兜底 0.15 秒。已由其他任务接走控制源时不改写该任务权限。每轮最多一次弧线，初始化不成功也不自动重试；若前端已初始化则不再移动。

初始化运动通过原 `/r680_nav/chassis_cmd_vel` → 独立 command_mux → `/r680_base/cmd_vel`；不创建第二个底盘驱动，不修改底盘仲裁，不开启 Nav2 的普通输出门。`--enable-motion`、`--auto-vio-init`、`--agent-control` 与此实验参数互斥。原 `--auto-vio-init` 仍是此前的安全链预览，与此一次性实验不同。

结果在本轮 `init_motion.json`，详细日志在 `logs/init_motion.log`。根入口现分别显示自动运动初始化状态和 OpenVINS 的 initialized/mode/reason，避免将“自动运动初始化关闭”误认为“估计器初始化关闭”。本工具静默结束不代表视觉健康、历史地图匹配或导航精度验收；须查看结果及里程计。

软件验证使用隔离 ROS 域 198、模拟传感器和真实 command_mux，域内没有底盘驱动。软件验证不能替代实车刹停、运动响应或定位精度验收。

## 2026-10-13 一次实车记录

本轮在手柄 DISCONNECTED、普通 Nav2 硬件输出关闭时，实际获得一次 AUTO/NAV 并发出动作。记录目录为 `/home/orin/nav_run/openvins_auto_init_20261013/live_once`，对应启动日志 `/home/orin/nav_run/nav-20261013-191510-245810`。没有重复实车动作。

- 非零命令持续约 0.57 秒，命令峰值 0.2 m/s、0.5 rad/s；轮速峰值约 0.178 m/s、0.109 rad/s。
- 包含停止过程的轮速累计路程约 0.0764 m、累计转角 0.0421 rad；这些是轮速遥测，不是外部测量真值，也不是已达到目标角速度的证明。
- 停止触发后约 20 ms，底盘命令已为零；末次非零命令后约 0.48 秒，轮速低于静止判据。仲裁交回 MANUAL，撤销 AUTO 授权；最终独立底盘服务 active、轮速为零且无导航命令发布者。
- 首个 initialized 状态在动作停止约 0.45 秒后出现，随后 reason=ok，产生 1286 条 VIO odom、746 条 mapping odom 和地图 TF；Nav2 日志确认 Managed nodes are active / startup completed。脚本因先前误判最终退出，因此此次不能算完整的一键启动成功。

这次提前停止的直接原因是辅助脚本将 `imu_age_s=-0.00009489059448242188` 判为失效。前端 `fresh()` 已允许最多 50 ms 的时间戳提前量，辅助脚本却要求 age>=0，时间契约不一致。已将辅助脚本的下界对齐前端 -0.05 s；IMU 100 ms、图像 350 ms 的超时上界保持不变，未知数据 -1 仍被拒绝。隔离测试使用这次真实微小负值作为无手柄正例，并覆盖超过未来容差、IMU 超时和图像超时的停止反例。此修正尚未重新进行实车运动验证。

标定、定位精度、历史地图实际匹配和长时间视觉遮挡没有在本轮验收；自动运动只用于初始化激励。
