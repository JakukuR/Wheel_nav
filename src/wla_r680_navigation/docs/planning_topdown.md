# 实车规划页 2D 俯视图

入口：http://192.168.9.118:18081/planning

页面上方为二维俯视图，下方保留 RGB 几何投影。车体固定在原点，+X 向上、+Y 向左；可选 4/8/12 米纵向视野。浏览器 Canvas 绘制，无新增 ROS 发布者或控制接口。

## 数据语义

- 红色点：现有局部深度障碍点的 XY 投影，限制在车体 ±8 m 范围，最多 3000 个显示采样点。
- 已知空闲与占用区域：跟随器原始 OccupancyGrid，保留栅格原点平移和旋转。未知区域保留深色背景，不把没有点的地方当空闲。单图最多 40000 格。
- 路径：现有 person/object（odom 模式亦支持导航）局部路径，空消息立即清除。
- 目标：检测器已进行深度与相机外参转换后的 distance/yaw，还原为车体 XY。只标注新鲜观测；人物跟随状态中的完整目标 ID 与当前检测 ID 完全一致且任务启用时，标黄为锁定目标。
- 车辆显示模型半径 0.19 m，虚线为额外 0.10 m 障碍余量，仅作可视化说明。
- 几何显示最长源年龄 0.5 s；目标按生产者 TTL（当前 0.3 s）且不超过 0.5 s。数据过期、无 TF、代次不符时不借用旧目标或猜测坐标。
- 各层是各自采集时刻的车体局部快照，未进行跨时刻运动补偿，不能当作严格同步的全局地图。
- 俯视图不依赖 RGB/CameraInfo，保留自己的数据状态；网络断开清空，暂停明确显示非实时。
- 跟随任务停止时可能只有深度点与检测目标；栅格和路径需要跟随器发布有效结果。

## 19 cm 车体标定更新

用户指定半径改为 0.19 m，模型直径 0.38 m；障碍余量保持 0.10 m，含余量的名义直径为 0.58 m。规划核心、地图自车清除范围、行人趋近偏置和俯视图统一使用新尺寸。正常跟随表面距离仍为 0.40 m，停止参考 0.36 m，允许临时最近表面距离 0.10 m，相应中心距调整为 0.87/0.83/0.57 m。栅格离散和额外检查仍可能使实际停止更早。
