## 本次改动

不修改障碍范围、点数判据、停稳时间或运动限制。新增初始化诊断：

- `input_blocker`：输入缺失/无效、安全生命周期、近场障碍、深度不足或车轮未停稳。
- `blocking_point_count`、`first_blocking_point_xyz`、`blocking_cloud_fresh`：最近有效安全云的阻塞点数量、首点坐标和该云的新鲜度。新鲜度为 false 时不能把坐标当作当前障碍。
