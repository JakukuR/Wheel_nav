# 便捷选择跟随目标

在车端 `~/ros2_ws` 运行，不需要复制整串人物 ID。

交互选择（推荐）：

```bash
./r680_follow_trial.sh follow --allow-motion --continuous
```

脚本列出当前有效人物的序号、画面 ID、距离和左右方位。输入序号后回车
开始跟随；`r` 刷新列表，`q` 或 Ctrl+C 取消选择。只有一个人时也需要明确选择。
跟随开始后 Ctrl+C 请求停止，原 1.5 秒租约与心跳处理保持不变。

已看清画面中的短 ID 时，也可以直接指定：

```bash
./r680_follow_trial.sh follow --target-id 190 --allow-motion --continuous
```

短 ID 表示当前检测画面中的人物，启动前解析为当前完整 ID；也支持
`29:190` 或完整 `session:epoch:id`。短 ID 不是跨相机重启的永久身份。
列表编号与画面 ID 不同：交互输入的是左侧序号，`--target-id` 输入的是画面 ID。

只显示正在检测、具有有效距离与方位的人物。多人时不按距离自动选择。
等待输入时持续接收 ROS 数据；选择绑定显示时的完整 ID，不随列表重排或
检测器代次变化而重新解释。人已消失、数据过期、ID 不唯一或已有其他任务时
不会发起跟随。非交互脚本必须显式传 `--target-id`。

本次仅修改试跑客户端，无需重启相机、检测、跟随或网页进程。
验证：16 项客户端/选择回归测试通过，包括持续模式、停止租约、拒绝重复或
失效 ID、交互取消、列表重排及检测器重启后的 ID 复用。
