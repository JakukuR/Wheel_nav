# 人物跟随主链路（2026-10-23）

## 当前契约

唯一跟随配置是 `config/sim_follow.yaml` 的 `tracker_follow`。命令选择完整 detector ID 后，立即创建 `FollowTracker`；同帧目标点云屏蔽完成后才将该深度帧交给地图与 MPC。ReID 在独立的回调/控制时钟路径收集模板，不等待 MPC 或深度工作线程。

| 主状态 | 进入条件 | 行为 |
| --- | --- | --- |
| binding | 刚接受命令，等待图像时刻的有效位姿 | 保留选定 ID，等待几何证据 |
| tracking | 当前 ID 的新鲜、连续几何观测 | Kalman 更新，MPC 跟随 |
| coasting | 观测缺失，距最后真实观测不超过 2 秒 | 有界 Kalman 预测跟随 |
| holding | 几何位置突变，距最后观测不超过 2 秒 | 暂停运动，等待几何确认或 ReID |
| search_last_seen | 超过 2 秒未接受新观测 | 以最后真实位置为固定搜索目标，MPC 速度上限 0.20 m/s |
| search_heading | 到达最后位置 0.35 m + 0.10 m 容差内 | 停止平移，先对准消失前可靠运动方向；速度不可靠则朝最后观测方位。对准后 ±0.60 rad 扫描，周期 8 秒，角速度上限 0.30 rad/s |

到达搜索点后状态锁存，不因位置噪声来回切换。预测不会延伸最后真实位置，也不会刷新观测时间。Kalman 预测位置最多外推 2 秒。以上空间参考均为轮速积分的局部参考系。

任务只受显式停止、租约到期、检测代际改变、检测关闭、急停与运动权限撤销等任务条件终止。ReID 不再有注册超时、suspect 停车或丢失 30 秒释放任务的权力。搜索持续期间仍需客户端续租和新鲜的相机、检测批次、轮速数据。

## ReID 恢复旁路

- 主目标可见时，只从已接受几何的当前 ID 收集质量合格的特征；两帧相符才建立模板。
- 特征导出/发布异常、质量失败、低相似度、邻人干扰只影响模板收集；持续重试，不改变主状态或速度权限。检测端先发布几何与目标掩码，再发布旁路特征；旁路异常不再触发检测代际重置。
- 检测器内部已有的 BoxMOT 原生关联仍复用 OSNet；本轮未替换其关联算法。整个检测器或 GPU 推理失效仍属于主传感器故障，会停止输出。
- 保留最初两个模板，后续高相似度模板有界更新（共最多 8 个）。
- 主目标不可见/几何断裂时，使用外观、空间门、候选差距及连续确认寻找目标；没有证据或候选歧义会清空连续确认计数。
- 成功后重新绑定当前 detector ID，递增 revision；旧规划、旧掩码和旧特征不得跨 revision 继续使用。
- 初始空间半径 0.45 m，随丢失时间以 0.25 m/s 增长，最大 1.50 m；相似度 0.80、差距 0.08，默认连续 3 帧。超出空间门的目标不会自动接管，需要实际数据评估这些参数。
- 没有成功采集模板时，新 ID 无法靠 ReID 恢复；任务仍继续搜索。同一 ID 可通过连续几何确认恢复。

## 点云与 MPC

检测端的掩码包包含 `requested_target_id`、`target_revision`、`target_present`。严格匹配 request/session/epoch/revision、图像尺寸、光学帧和深度源时间戳。

目标存在时必须确实滤除目标像素；目标不存在时必须有检测端同帧明确的 `target_present=false`。未收到包不等于目标不存在，不能把原始目标深度直接交给地图。配对器优先选择最新的已配对帧，不用更新但未配对的帧挤掉有效帧。

当前目标框过滤保留明显更近的前景；旧地图命中只允许由同帧分割确认的目标像素和同步几何撤销，不按预测坐标清空整片区域。几何缓存独立于 MPC 的处理延迟。

主链路跳过旧 `BlockedRecovery` 的 wait/hold 前置否决，MPC 直接采样并检查真实障碍、旁人和制动范围内未知空间。原有局部空闲先验参数保留；这不是传感器观测。原始仿真核心仍有被参考测试使用的恢复算法，但主跟随入口固定启用 direct_tracking，不再把该算法当作状态机。

输出端再次校验任务、revision、阶段和结果 TTL；计算过程中若进入 holding、搜索或重新绑定，旧阶段命令不能继续输出。

## 人物历史与 MPC 参考（时间窗口 + 三阶贝塞尔）

- `target_history_window_s=5.0`，`target_history_sample_period_s=0.4`。按已接受观测的源时间，在固定时间网格上重采样 Kalman 校正位置；两次连续真实观测之间线性插值，通常保留 12～13 个等间隔历史点，另带最新观测端点（合计最多 14 点）。每次新观测删除窗口外旧点。窗口参数限 2～20 秒、间隔限 0.2～1 秒，窗口/间隔不超过 64。
- 不把机器人初始位置、Kalman 无观测预测、MPC 预测轨迹写进人物历史。相邻已接受观测间隔超过两倍传感器新鲜度（默认 0.6 秒）时，重建采样序列，不插值补造失踪期间的位置。重新绑定 ID 或几何重置沿用原有 revision 重置规则。
- 目标不可见时，窗口冻结在最后真实观测时刻，保留有限的消失前路径；不随搜索时间增长，也不在搜索途中删空。仍执行最多 2 秒 Kalman 预测，然后前往最后真实位置并按既有方向规则搜索。
- 稀疏点先去除 3 cm 内的连续抖动，内部节点作局部平滑，位移限 5 cm、两端固定。每对相邻节点用一段三阶贝塞尔连接；相邻段共用切向控制柄，控制柄限 5 cm 且不超过邻接弦长的三分之一。每段固定采样 8 个点，默认曲线最多 105 点，计算量不随任务运行时间增长。
- 主链路直接把曲线用于 MPC 的弧长参考、朝向引导和原有参考误差评分，跳过旧宽转弯偏移与弹性平滑。必要时添加机器人到曲线起点的接入段；当前预测目标只作末端延伸，不回写观测历史。当前预测和接入段最多再增加两个点。
- 平滑曲线是参考，不代表已验证可通行。障碍物、其他人物、未知空间、目标间距和运动学检查仍由原有 MPC 候选检验执行；没有放宽传感器时效或结果 TTL。
- `/r680/person_follow/local_path` 现在发布实际送入 MPC 的参考曲线（含必要的接入段和当前目标端点），不再发布未经处理的历史折线，也不代表获选的机器人 rollout。`diagnostics.planner_target` 增加参考方法、历史点数、参考点数及采样时间窗口信息。

这是时间窗口裁剪，尚未引入已走路段消费或交叉路径的单向进度约束；窗口内折返仍由现有最近线段投影选择。5 秒之前尚未经过的拐角也可能随窗口淘汰，实机需观察机器人落后时的表现。

本次参考路径改动的验证范围：Python 静态编译、代码差异审查、Orin 上独立目录的 colcon 构建；未执行行为测试或实机运动。构建目录为 `.runtime/follow-bezier-20261023/`，未替换当前主安装目录、未重启 follower、未自动选择 ID 或发起 follow。部署时需要明确使用新构建或重新构建主安装目录，并核对上述两个参数和 `reference_method=windowed_cubic_bezier`。

## 清理与边界

删除 `geometry_binding.py`、`identity_supervisor.py`、`reid_identity.py`、`follow_policy.py`，删除 compatibility/first_batch 两套配置、旧参数和主节点兼容分支，并移除仅验证这些废弃行为的测试。其余测试保留；同帧掩码既有 fixture 更新到新协议。状态里的 `geometry_binding` / `identity_supervision` 字段名保留给现有诊断消费者，内容分别来自唯一 tracker 与恢复旁路。

`backend=legacy` 仍被 launch 明确支持，提供 `approach_interact`；本次没有删除这条仍有用途的入口。主跟随默认 `backend=sim`。默认 `enable_motion=false`，本次不会启用运动。
