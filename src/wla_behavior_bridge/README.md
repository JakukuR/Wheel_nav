# wla_behavior_bridge

2026-11-09 按当前源码整理。

Agent 人物 API、语义 API、共享感知适配器、导航任务网关和任务速度门。脚本依赖外部 Wheel_Legged_Agent 的 wla_sim；不把该源码复制进本包。agent_semantic_api 默认预览，behavior_bridge 的速度输出默认 task_safe_preview。

框架见 [工作区总览](../../docs/ros2_ws_architecture.md)，入口/参数/构建与检查见 [操作手册](../../docs/ros2_ws_operations.md)。
